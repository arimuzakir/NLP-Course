# Instructor Guide

## Teaching pattern
**Explain → Demonstrate → Guided Practice → Challenge → Discussion → Project Connection**

Tidak ada sesi khusus quiz/mid/UAS. Setiap minggu menghasilkan evidence of learning.

## S2 emphasis
Mahasiswa harus:
- menjelaskan alasan pemilihan metode,
- memahami asumsi,
- membuat eksperimen fair,
- mengevaluasi,
- melakukan error analysis,
- dan menyampaikan hasil secara ilmiah.

## Project continuity
Final project dimulai minggu 11, tetapi dosen dapat meminta mahasiswa mencatat calon topik sejak minggu 1.
