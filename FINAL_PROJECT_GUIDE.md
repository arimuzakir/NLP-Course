# Final Project Guide

## Target

Satu sistem NLP end-to-end yang memiliki:
1. problem statement,
2. research questions,
3. dataset/data card,
4. preprocessing,
5. baseline,
6. minimal satu model pembanding,
7. evaluation,
8. error analysis,
9. reproducibility,
10. final report dan presentation.

## Contoh task
Text classification, sentiment analysis, toxic/cyberbullying detection, NER, semantic similarity, information extraction, retrieval, QA sederhana, atau task NLP lain yang disetujui.

## Aturan eksperimen
- Gunakan baseline.
- Gunakan split yang jelas.
- Catat random seed.
- Ubah satu faktor dalam satu eksperimen.
- Jangan hanya melaporkan accuracy.
- Analisis error.
- Dokumentasikan keterbatasan.

## Milestone
Week 11: proposal + data card.
Week 12: baseline.
Week 13: model comparison.
Week 14: error analysis + improvement.
Week 15: presentation.
Week 16: release.
