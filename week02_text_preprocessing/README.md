## Tujuan

- Case folding, whitespace, punctuation, URL, mention, emoji, stopword, stemming/lemmatization memiliki trade-off.
- Preprocessing yang terlalu agresif dapat menghilangkan signal.

5. Tulis `reflection.md`.

## Latihan
