# Student Workflow

1. Fork repository.
2. Buat branch: `student/<nama>/<project>`.
3. Jangan mengubah dataset utama.
4. Jalankan notebook dari atas.
5. Simpan hasil penting di `results/`.
6. Tambahkan reflection.
7. Untuk final project gunakan `final_project_template`.
8. Pastikan README menjelaskan cara menjalankan project.
