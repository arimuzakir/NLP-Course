# Minggu 1 - NLP, Pipeline, dan Tokenization

## Tujuan
- NLP sebagai gabungan linguistik, computing, statistik, dan machine learning.
- Pipeline umum: raw text → preprocessing → representation → model → evaluation.
- Tokenization menentukan unit analisis: sentence, word, character, subword.
- Tokenization dapat berbeda untuk bahasa formal, social media, dan domain khusus.

## Cara belajar
1. Baca `materi.md`.
2. Jalankan notebook dari cell pertama.
3. Jangan hanya menjalankan kode; ubah satu bagian.
4. Catat hasil eksperimen.
5. Tulis `reflection.md`.

## Latihan
Bangun tokenizer whitespace dan regex. Uji pada URL, hashtag, mention, angka, emoji, kata berimbuhan, dan punctuation.
