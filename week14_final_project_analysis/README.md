# Minggu 14 - Final Project: Error Analysis

## Tujuan
- Error analysis harus berbasis contoh nyata.
- Kategori error harus didukung data.
- Perbaikan harus berasal dari temuan error.

## Cara belajar
1. Baca `materi.md`.
2. Jalankan notebook dari cell pertama.
3. Jangan hanya menjalankan kode; ubah satu bagian.
4. Catat hasil eksperimen.
5. Tulis `reflection.md`.

## Latihan
Analisis minimal 20 error dan lakukan satu eksperimen perbaikan.
