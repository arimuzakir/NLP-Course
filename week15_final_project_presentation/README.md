# Minggu 15 - Final Project: Scientific Presentation

## Tujuan
- Presentasi ilmiah harus menjelaskan problem, method, evidence, limitation.
- Metric tanpa interpretasi tidak cukup.
- Q&A menguji pemahaman.

## Cara belajar
1. Baca `materi.md`.
2. Jalankan notebook dari cell pertama.
3. Jangan hanya menjalankan kode; ubah satu bagian.
4. Catat hasil eksperimen.
5. Tulis `reflection.md`.

## Latihan
Siapkan presentasi 10-15 menit dan demo.

## Pertanyaan S2
- Mengapa metode ini dipilih?
- Apa asumsi metode?
- Apa sumber error?
- Bagaimana eksperimen dapat dibuat lebih fair?
- Apa yang dapat diteliti lebih lanjut?

## Deliverable
Notebook yang sudah dijalankan + reflection.
