# Course Map

Pemetaan ini mempertahankan bahan kajian NLP pada RPS:
- pengantar NLP, tokenisasi, preprocessing,
- struktur kalimat dan parsing,
- semantik dan word embeddings,
- n-grams, Markov, Transformer/BERT,
- text classification dan NER,
- machine learning untuk NLP,
- pengembangan dan evaluasi project.

| Minggu | SUB-CPMK | Implementasi |
|---|---|---|
| 1-2 | 1601.1 | NLP, tokenization, preprocessing |
| 3 | 1601.2 | syntax/parsing |
| 4-5 | 1601.3 | semantics, vector space, embeddings |
| 6 | 1602.1 | language modeling |
| 7-8 | 1602.2 | classification, NER |
| 9-10 | 1602.3 | ML/deep learning, evaluation |
| 11-14 | 1602.4 | final project |
| 15-16 | 1602.5 | presentation, evaluation, release |

RPS formal tetap menjadi dokumen institusional. Repository ini adalah implementasi bahan ajar dan praktikum.
