# Assessment: Competency and Project Based

Tidak ada kuis, UTS, atau UAS terpisah.

## Evidence of learning

| Komponen | Bobot contoh |
|---|---:|
| Weekly laboratories | 25% |
| Mini-projects | 20% |
| Project proposal + data | 10% |
| Project experiments | 20% |
| Error analysis + reproducibility | 10% |
| Final report + presentation + release | 15% |

Bobot dapat disesuaikan dosen.

Yang dinilai bukan hanya skor model, tetapi:
- pemahaman konsep,
- ketepatan implementasi,
- experimental design,
- interpretasi,
- error analysis,
- reproducibility,
- scientific communication.
