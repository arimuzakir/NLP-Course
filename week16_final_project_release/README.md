# Minggu 16 - Final Project: Reproducible Release

## Tujuan
- Repository yang baik dapat digunakan ulang oleh orang lain.
- README harus menjelaskan installation, data, training, evaluation, dan limitations.
- Release adalah bagian dari scientific communication.

## Cara belajar
1. Baca `materi.md`.
2. Jalankan notebook dari cell pertama.
3. Jangan hanya menjalankan kode; ubah satu bagian.
4. Catat hasil eksperimen.
5. Tulis `reflection.md`.

## Latihan
Finalisasi report, code, README, results, slides, dan release.

- Apa asumsi metode?

- Bagaimana eksperimen dapat dibuat lebih fair?

## Deliverable
Notebook yang sudah dijalankan + reflection.
